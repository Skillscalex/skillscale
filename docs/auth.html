Safety & Trust

This GitHub Pages site is a static public catalog for Skillscale. It does not ask for passwords, phone numbers, one-time codes, wallet signatures, credit-card numbers, or private API keys.

Important browser warning note If a browser labels this Pages URL as dangerous, treat that warning seriously while the site is reviewed. The repository has been changed so the public Pages surface is informational and does not contain a login form.

Marketplace Safety

Skill listings are inert catalog entries. Install commands and README excerpts are untrusted text until scanned and verified.

Skill Scanner

The ingestion loop uses a local Skillspectre-style static scanner to flag risky commands, secret access, prompt injection, and external execution.

Governed Agents

Agentic Civilization cycles default to simulated actions and governance decisions instead of real external execution.

  • Do not paste secrets, passwords, private tokens, or recovery phrases into any static GitHub Pages demo.
  • Do not run a scraped skill until its source, permissions, and security notes are reviewed.
  • Report suspicious content through the repository security contact listed in /.well-known/security.txt.
